# 布局规则与验收边界

1. **职责与素材分开。** 先决定节点是什么、属于谁、是否可交互，再决定裁剪。源截图保留作证据，不用作运行时背景。无法从被遮挡或混色的源图恢复的像素不能标成已恢复。
2. **同模板同画布。** 轮廓不同不等于节点尺寸不同。同模板用相同导出画布和锚点，透明留边，不拉伸图案。展示专用、缺失字体的静态字样可以与图标合切；昵称、编号、余额等运行时内容保留为 Label，背景板独立。
3. **区分四种尺寸。** 原图裁框是截图像素坐标，导出画布含透明补边；元素尺寸属于设计单位，点击范围由交互容器独立负责。视觉和触摸不要绑定在同一层级；徽标也不接收输入。
4. **先停靠，再排列子项。** 安全区负责停靠范围；容器的对齐、列表方向、行列间距与溢出策略单独记录。固定槽位和可折叠槽位应区分，不把列表截图当作一张图。Creator 导出时分别验证 Widget、Layout 和触摸行为，这个 demo 只验证网页几何。
5. **小图标按像素核对。** 放大看源图、alpha 和浅深底合成，检查边缘缺失和画布裁断。只补有源图依据的可见像素；不清楚是背景还是描边的，标记待复核。

验收顺序：源图定位 → 透明素材尺寸 → 节点父子关系 → 多视口布局 → 实际 Creator 导入 → 真机交互。后两项不属于本分支已验证范围。
