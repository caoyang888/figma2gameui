# 截图拆分检查器 Demo
这是此前截图实验的**检查器代码**，搭配重新制作的合成样例。它不修改现有 Figma 插件，不包含原游戏截图、切图或原样本数据。

## 启动

在本目录运行：

```sh
python3 build.py
```

用浏览器打开生成的 `demo.html`。这一步只用 Python 标准库，页面自包含，不需要联网，也不需要安装仓库的前端依赖。

- 在源图、节点树或素材格中点选一个元素，查看层级、元素设计尺寸和 PNG 或运行时数据槽。
- 切换三档视口、选择容器节点，比较容器的区域、对齐规则和独立命中区。
- 可以下载 PNG 或不含图像数据的节点 JSON。保留四种尺寸：源裁框、素材画布、元素设计尺寸、点击区。

`fixture.json` 已准备好。如需重新生成合成数据，直接执行 `python3 generate-fixture.py`。 `demo.html` 是生成物，不提交。

**边界：** 这个 demo 读预先整理的布局数据，没有自动识别任意截图。视口及命中区是网页几何预览，不代表 Cocos 的实际触摸行为；尚未生成或验证 Creator 3.8.8 的 `.prefab`。

## 测试

生成页面后运行 `node smoke.mjs`，检查素材尺寸与透明标记，以及三个视口的命中区边界、最小尺寸和交叠。可选 `python3 smoke.py` 在安装 Playwright 和 Chromium 后运行浏览器交互测试。
