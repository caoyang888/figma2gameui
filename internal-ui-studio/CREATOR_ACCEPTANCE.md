# Creator 3.8.8 实际导入验收

1. 用 `npm run sample -- /tmp/ui-studio-creator-smoke.zip` 生成合成资源包；用 Creator 3.8.8 新建空 2D 工程，不使用公司在产工程。
2. 将 ZIP 内 `assets` 下目录及同名 `.meta` 拷入空工程。等待资产数据库完成导入，打开两个预制体；降级导入、丢失类、丢失贴图都算失败，保留 Creator 日志。
3. 核对预制体树、SpriteFrame、可编辑 Label、独立 Button 命中框和 Layout 列表；按钮无业务回调，可临时绑定一个只计数的本地测试回调。加一个 Layout 项应重排，重新切换分辨率需人工检查图面。
4. 记录两预制体是否指向同一个贴图 SpriteFrame。再覆盖导入同一份 ZIP，确认 Editor 的 UUID 未变化，不新增一份图片或预制体。记录导入前后元数据差异；不把合法的引擎补字段误报为 ID 变化。
5. 选定允许的真实 AI 服务后，用内置合成图验证模型连接，再用一套合成切图导入验收；连通成功但图像答案错误，不能启用该模型。

此表是验收清单，不是已经执行的记录。
