# 后端迁移：Node.js + TypeScript

目标：公司内部工作台只运行一个 Node.js 服务。浏览器界面、API 路径、SQLite 数据和 Cocos Creator 3.8.8 资源身份保持兼容。Figma 插件不引回本分支。

1. 对照既有行为：项目、素材、模型设置、分析、审核、单界面与全项目 ZIP。
2. 迁移实现：项目存储与旧密钥兼容；保留上传限制、像素去重、模型地址限制及随机图片探测；复用现有浏览器 UI。
3. 上线前回归：在隔离目录用旧数据库样本验证读取和写入；同数据对照 prefab/UUID/资源路径；执行 Web API 流程；用干净的安装验证命令并更新 README。
4. 不将模拟模型测试或 ZIP 静态回归视为真实 AI 服务与 Creator 编辑器验收。切换实际服务前停掉旧服务，并备份数据卷、SQLite 和加密密钥。
