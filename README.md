# 公司内部 UI 制作台

按项目管理切图、字体和参考图，使用经过识图校验的模型分析界面结构，人工确认后导出 Cocos Creator 3.8.8 预制体与资源包。

后端使用 Node.js 24 + TypeScript；从仓库根目录执行 `cd internal-ui-studio && npm ci`，再用 `F2_DEV_LOCAL=1 npm start` 启动本地工作台。
